# Fidget — CLAUDE.md

## Project Overview

Fidget is a macOS menu bar app that prevents screen sleep by periodically moving the mouse cursor or running `caffeinate`. It runs as a `LSUIElement` (no Dock icon), showing only in the menu bar.

## Architecture

### Core Class: `FidgetApp`

Single-class app in `fidget.py`:

```python
class FidgetApp:
    def __init__(self)       # Sets up QApplication, tray icon, timers; starts jiggling
    def setup_tray_icon()    # Builds QSystemTrayIcon + QMenu with submenus
    def find_icon_path()     # Locates fidget.png relative to script
    def start_jiggling()     # Enables jiggle_timer + countdown_timer; starts caffeinate on macOS
    def stop_jiggling()      # Stops timers; terminates caffeinate
    def start_caffeinate()   # Spawns subprocess: caffeinate -d -i
    def stop_caffeinate()    # Terminates caffeinate subprocess
    def perform_jiggle()     # Called by jiggle_timer; uses caffeinate or mouse movement
    def move_mouse_relative(dx, dy)  # Platform-specific relative mouse move
    def get_mouse_position() # Returns (x, y, screen_index) with multi-monitor support
    def set_mouse_position(x, y)     # Platform-specific absolute move
    def set_interval(seconds)        # Updates jiggle interval, restarts timer
    def set_movement_range(pixels)   # Updates movement range; toggles caffeinate
    def update_countdown()           # Called every 1s by countdown_timer; updates status text
    def update_menu_state()          # Syncs checkmarks + visibility to current state
    def run()                        # Calls app.exec() (main loop)
```

### Two Timers

- **`jiggle_timer`** — fires every `interval` seconds → calls `perform_jiggle()`
- **`countdown_timer`** — fires every 1000ms → calls `update_countdown()` to update status text

### Sleep Prevention Strategy (macOS)

1. **Default** (no `--force_mouse`): runs `caffeinate -d -i` as a background subprocess. Mouse may also move.
2. **Range = 0 ("Script Awake")**: caffeinate only, no mouse movement.
3. **`--force_mouse`**: mouse movement only (via AppleScript `osascript`, falls back to Quartz CGEvent).

### Mouse Movement on macOS

Primary: AppleScript via `osascript`:
```applescript
tell application "System Events"
    set mouse location to {x, y}
end tell
```
Fallback: Quartz `CGEventCreateMouseEvent` + `CGEventPost`.

## Command-Line Arguments

```
--interval INT    Jiggle interval in seconds (default: 240 = 4m)
--distance INT    Max mouse movement in pixels (default: 5)
--verbose         Log to /tmp/fidget.log + stderr
--force_mouse     Force mouse movement instead of caffeinate
```

## Known Issues / Hard-Won Knowledge

- **`QAction` import**: Must come from `PyQt6.QtGui`, not `PyQt6.QtWidgets`. Bug manifests as symbol-not-found crash on launch.
- **Lambda scope in menus**: Use `create_interval_handler(s=seconds)` pattern to capture loop variables — direct lambdas all resolve to the last value.
- **`LSUIElement: True`** in plist is required to hide Dock icon; set in `setup.py` OPTIONS.
- **`app.setQuitOnLastWindowClosed(False)`** is required — without it, the app quits when there are no windows.
- **`caffeinate -d -i`** prevents display sleep (`-d`) and idle sleep (`-i`). Runs as a subprocess, not a signal.
- **Mouse position unchanged warning** is expected when `caffeinate` is handling sleep prevention (no actual mouse move happens).
- **`setup.py` is regenerated** by `build_app.sh` — don't edit it directly, it will be overwritten.
